# 医疗大健康 · 内容合规审核引擎

一个面向医疗大健康赛道的内容安全自检工具，用于在发布前自动识别文案中的**极限词、医疗功效宣称违禁词、平台引流限流话术**，并给出合规替换建议。

## 在线访问

**直接打开（推荐）：**

```
https://brunobobby7713-svg.github.io/medical-words/
```

打开后会自动进入检测引擎页面。

> 如果上面的短链接打不开，也可以直接访问：
> `https://brunobobby7713-svg.github.io/medical-words/content-safety-engine.html`

## 文件说明

| 文件 | 作用 |
|------|------|
| `content-safety-engine.html` | 检测引擎主页面（单文件，打开即用） |
| `medical-words.txt` | 主词库，引擎默认从此文件实时同步 |
| `medical-words.json` | 备用词库（JSON 格式） |
| `index.html` | 短链接入口，自动跳转到检测引擎 |

## 如何维护词库

1. 打开本仓库中的 `medical-words.txt`
2. 点击右上角「编辑」按钮（铅笔图标）
3. 按 `词语|分类|替换词` 格式增删改，例如：

```text
最|极限词|很
根治|医疗警示|调理
私域|引流限流|社群
```

4. 拉到最下方点击「Commit changes」
5. 所有正在使用网站的人会在 5 秒内自动同步最新词库

**分类说明：**
- `极限词`：广告法禁用的绝对化用语（如“最”“第一”“顶级”）
- `医疗警示`：医疗/功效宣称违禁词（如“根治”“治愈”“抗癌”）
- `引流限流`：平台导流/促销话术（如“私域”“评论区扣1”“免费送”）

## 技术特点

- 纯前端单文件，无需后端，打开即用
- DFA（确定性有限状态机）高性能匹配
- 云端词库实时同步（默认每 5 秒刷新）
- 支持替换词模式、命中高亮、分类统计、性能压测

本工具仅用于内容发布前的合规自检，词库由使用方自行维护。请勿将本工具用于规避平台监管或传播违规内容。
