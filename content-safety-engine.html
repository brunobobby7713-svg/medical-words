算法原理 · DFA / Trie 状态机

引擎将敏感词构建为一棵 Trie 树，并在扫描文本时以 O(n) 线性时间完成匹配（n 为文本长度，与词库规模无关）。虚线圈标记 终止状态——一旦走到该节点即判定命中，支持最长匹配与抗干扰跳字（如 最*佳 仍可识别为 最佳）。

📖 使用说明与注意事项

这是一个发布前自查工具——把要发的文案粘进去，自动标出易踩雷的违禁词/限流词，并给出合规替换建议。无需安装，打开即用。

一、怎么打开

推荐发这个短链接给任何人，打开即用：

https://brunobobby7713-svg.github.io/medical-words/

也可双击本地 content-safety-engine.html，或把该文件发给同事。

⚠️ 真正的网站是带 .html 的链接，别把 medical-words.txt（词库数据）当网站发。

二、日常怎么用

  • 检测：删掉示例，粘贴你的文案，自动实时标红；也可点「开始检测」。
  • 三色含义：🔴粉=极限词（广告法禁用）｜🟠橙=医疗警示（功效违禁）｜🔵青=引流限流（易触发限流）。
  • 替换词模式：勾选后下方显示绿色合规替换词，如 ~~根治~~ → 调理。
  • 高频话术演示：点一下铺满引流限流词，给领导看最直观。
  • 性能压测：点「注入 10 万字压测」展示引擎吞吐指标。

三、全员建议加词（任何人可提交）

页面「词库管理」区最下方有 💡 全员建议加词 表单：填词 + 选分类 + 填替换词（可选），点「提交建议」→ 自动跳到 GitHub 预填好的提交页 → 点 Submit 即可。管理员审核合并后，全员 5 秒内自动更新。

注意：提交建议需对方有 GitHub 账号（免费）；提交是"建议"，不是免审核直接生效。

四、怎么加词 / 改词（管理员）

打开仓库 github.com/brunobobby7713-svg/medical-words → 点 medical-words.txt → 铅笔编辑 → 按格式改：

词语|分类|替换词　例：最|极限词|很　抗衰|医疗警示|年轻化

Commit 后全员 5 秒自动同步。分类只能三选一：极限词 / 医疗警示 / 引流限流。第三列替换词可省略（省略只标红不打码）。

五、注意事项（必看）

  • 词库 URL 框别填网页链接：只能填 .txt/.json 结尾的词库地址（已内置好，一般不动）。填小红书/公众号链接会报错。
  • 加词走正规入口：用网站「全员建议加词」或 GitHub 编辑，别试图把笔记链接粘进 URL 框"自动抓词"（做不到）。
  • 两类改动麻烦度不同：改词库 txt → 零上传、全员自动同步；改网站功能/界面才需重传 HTML（当前功能已做齐，短期不用）。
  • GitHub Pages 有延迟：上传/改文件后线上约 1-5 分钟才生效，稍等再刷新。
  • 建议加词是"建议制"：别人提交后需你审核合并才进共享库（想免审核需另搭后端）。
  • 改错了能回退：GitHub 里每个文件点 History 可看历史、一键恢复。
  • 换人接手：只需把短链接发过去，对方打开即用；词库维护权限在 GitHub 仓库设置分配。

六、合规底线

  • 本工具仅用于发布前合规自检，不是规避平台监管。
  • 词库自行维护，请勿添加政治类违禁词。
  • 替换词要写真正合规的词，别换汤不换药。
  • 标红只是提示"注意上下文"，非一刀切禁用——科普提"抗衰"没事，配上"免费领/评论区扣1"才易限流。
